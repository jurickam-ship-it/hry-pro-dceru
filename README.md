# Hry pro dceru

Offline prohlížečové hry pro tříletou dceru. Hraje se společně s tátou.

**Hrát online:** https://jurickam-ship-it.github.io/hry-pro-dceru/

## Aktivity

- Třídění podle barvy a tvaru
- Zvířátka („Kdo dělá bú?“)
- Pexeso (4 nebo 6 dvojic)
- Počítání do 5

## Pravidla

- Jen klik / dotyk, velké cíle
- Kolo 5–10 minut s jasným koncem
- Žádné body, reklamy, odkazy ani sběr dat
- Pokyny umí namluvit česky (Web Speech API)

## Lokálně

Otevři `index.html` dvojklikem, nebo:

```bash
python3 -m http.server 8080
```

Pak http://localhost:8080
