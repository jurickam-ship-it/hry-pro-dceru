# Hry s tátou

Offline hry pro dceru. Hraje se společně s tátou.

**Hrát:** https://jurickam-ship-it.github.io/hry-pro-dceru/

## Co tu je

- Třídění, zvířátka, pexeso a počítání
- Zobcová flétna: dech, držení, tóny há / á / gé / cé, ozvěna a tři písničky
- Líza mluví nahraným českým hlasem (složka `voice/`)
- Mikrofon umí poznat tón na skutečné flétně. Když nejde, táta potvrdí prstem
- Průběh zůstává jen v tomto prohlížeči

Žádné body, reklamy ani odesílání dat.
